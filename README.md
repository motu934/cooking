# 🍳 お料理教室 - クッキングシミュレーション 🍔

『Overcooked（オーバークック）』にインスパイアされた、ブラウザで手軽に遊べるリアルタイム飲食店クッキングシミュレーションゲームです！

---

## 🎮 ゲーム概要
- **ジャンル**: 飲食店マルチタスク調理アクション
- **対応プラットフォーム**: Webブラウザ (Chrome, Edge, Firefox, Safari等)
- **技術スタック**: HTML5 Canvas, Vanilla JavaScript, IndexedDB (データベース永続化)

---

## 🕹️ 操作方法
- **移動**: `W`, `A`, `S`, `D` キー
- **アクション**: `Space` キー (食材を取る / 調理台に置く / まな板で切る / 皿に盛る / 配膳する)

---

## 🥗 レシピと注文
| 料理名 | 必要な具材 | 完成ボーナス |
| :--- | :--- | :--- |
| **特製フレッシュサラダ** 🥗 | 🔪 カットトマト + 🔪 カットレタス | サラダ完成！ |
| **絶品ハンバーガー** 🍔 | 🍞 バンズ + 🥩 肉 + 🥬 レタス(丸ごと) + 🍅 トマト(丸ごと) | ボリューム満点！ |

---

## ⏱️ モード別の制限時間ルール
- **👤 シングルモード (1人プレイ)**
  - 初期タイム: **70秒**
  - サラダ配膳: **+10秒**
  - バーガー配膳: **+15秒**
- **👥 マルチモード (最大3人プレイ)**
  - 初期タイム: **60秒**
  - サラダ配膳: **+5秒**
  - バーガー配膳: **+10秒**
  - **合言葉システム**: リーダーが発行した4桁のパスワードを入力することで、別ウィンドウやタブから即座に合流・協力プレイが可能！

---

## 🗄️ データベース連携 (IndexedDB)
ブラウザ標準の本格データベース **IndexedDB** を内蔵しており、以下のデータを管理・永続化しています：
1. **`recipes` (レシピマスタ)**: 料理の材料、報酬スコア、制限時間ボーナスの定義
2. **`scores` (プレイ履歴)**: プレイ日時、モード（シングル/マルチ）、最終スコアの保存
